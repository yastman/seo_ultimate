# Полірувальна паста

Паста для полірування авто — абразивний склад для видалення подряпин, голограм та окислень з лакофарбового покриття. Якщо шукаєте пасту для полірування кузова автомобіля, важливо підібрати правильну абразивність — тоді засіб відновить глибину кольору без зайвого зняття лаку.

## Як обрати полірувальну пасту для авто

| Тип | Абразивність | Для кого |
|-----|--------------|----------|
| Важка (heavy cut) | Висока | Глибокі подряпини, риски від P1500 |
| Середня (medium cut) | Середня | Голограми, сліди від щіток |
| Фінішна (finish) | Мінімальна | Надання блиску, видалення розводів |

**Сценарії вибору:**
- **Якщо на лаку глибокі риски** → поліроль від подряпин або heavy cut паста
- **Якщо тільки голограми після обробки** → середня або фінішна
- **Якщо м'який японський лак** → починайте з меншої абразивності
- **Якщо пожовклі фари** → паста для полірування фар (окрема категорія)

### На що дивитися на етикетці

| Маркер | Значення |
|--------|----------|
| «Cut» + цифра | Ступінь абразивності (1–10) |
| «Compound» | Абразивний продукт (не фінішний) |
| «Polish» | Менш абразивна |
| «One-step» | Універсальний склад для одного проходу |

## Особливості роботи з полірувальною пастою для автомобіля

Склад працює у зв'язці з кругом — жорсткий круг підсилює абразивність, м'який — зменшує. Температура поверхні критична: перегрів вище 60°C може призвести до пропалу лаку. Працюйте секціями 40×40 см.

**Якщо склад підсихає на поверхні** → додайте пару крапель води або спеціального лубриканту.

## Що впливає на результат

| Фактор | Вплив |
|--------|-------|
| Твердість лаку | М'які (японці) потребують меншої абразивності |
| Тип круга | Поролон/мікрофібра/вовна дають різний зріз |
| Оберти машинки | Нижчі = безпечніше, вищі = агресивніше |

## FAQ

### Чим відрізняється від воску?

Паста для видалення подряпин — абразивний склад для корекції дефектів, вона знімає мікрошар лаку. Це засіб для видалення подряпин на авто, а не для захисту. Віск — захисне покриття без абразиву. Спочатку полірування (якщо потрібно), потім захист воском.

### Скільки засобу потрібно на одне авто?

**Якщо середній седан** → 50–100 грам на повну обробку одним етапом. Якщо триступенева корекція — відповідно більше.

### Чи можна полірувати вручну?

Так, але ефективність значно нижча. Набір паст для полірування авто вручну підходить для локальних дефектів або як тимчасовий захід.

- Якщо тільки голограми: фінішна паста достатня
