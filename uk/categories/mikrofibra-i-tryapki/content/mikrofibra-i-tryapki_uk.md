# Мікрофібра для авто

Якісна мікрофібра для авто — основа безпечного догляду без подряпин. Ганчірка для авто без розводів, рушник для сушки авто, серветки для авто — від вибору залежить, чи пошкодиться лак при поліруванні. Шкіра для протирання авто та серветка з штучної замші забезпечують ідеальний результат на склі.

## Як обрати мікрофібру для авто

| Тип | GSM | Призначення | Особливості |
|-----|-----|-------------|-------------|
| Ганчірка з мікрофібри | 200-350 | Полірування, скло | Без ворсинок на поверхні |
| Мікрофібра для сушки авто | 400-600 | Сушіння, протирання | Вбирає більше вологи |
| Вафельний рушник | 300-400 | Сушіння, скло | Швидке вбирання |
| Твіст | 700-1200 | Сушіння великих поверхонь | Максимальне вбирання |

### Сценарії вибору мікрофібри

**Якщо для сушіння кузова** — влаговбирна ганчірка для авто вафельного типу або твіст-мікрофібра з високим GSM. Вбирає воду без розтирання, зменшує ризик подряпин. Ганчірка для сушки має бути щонайменше 400 GSM.

**Якщо для полірування** — коротковорсова мікрофібра для полірування авто 300-400 GSM. Ганчірка для машини без розводів має бути без жорстких швів та етикеток.

**Якщо для скла** — мікрофібра для скла авто або серветки для скла. Гладка безворсова тканина не залишає ворсинок та забезпечує ідеальну прозорість. Ганчірка для скла авто має бути окремою від кузовних.

## На що дивитися при виборі мікрофібри

| Характеристика | Що означає | Рекомендація |
|----------------|------------|--------------|
| GSM (г/м²) | Щільність | Вище = вбирає більше |
| Склад | 70/30 або 80/20 | Більше поліаміду = м'якіше |
| Шви | Ризик подряпин | Без швів або зі швами всередину |
| Розмір | Площа роботи | 40×40 см універсальний |

## Правила догляду

Прайте мікрофібру окремо від іншого одягу. Не використовуйте кондиціонер — він забиває волокна та погіршує вбирання. Сушіть при низькій температурі.

**Ознаки заміни:** жорсткість, втрата вбирання, розлізання волокон, стійкі плями від масел.

## FAQ

### Скільки серветок потрібно для догляду?

Мінімальний набір мікрофібри: 2-3 для сушіння, 2-3 для полірування, 1-2 для скла, 1-2 для інтер'єру. Краще мати запас — брудну ганчірку для миття авто не можна використовувати до прання.

### Яка мікрофібра для сушіння найкраща?

Твіст-структура з GSM 700+ для великих поверхонь. Вафельна для деталей та швидкого збору води. Обидва типи ганчірок для сушіння машини працюють добре.

### Чи можна прати з іншими речами?

Не рекомендовано. Інші тканини залишають ворс, який потім переноситься на кузов. Пральний порошок без фосфатів, температура до 60°C.

---

**Підсумок:** Для сушіння — висока GSM мікрофібра для сушки (твіст або вафля). Для полірування — коротковорсова без швів. Тримайте окремий набір мікрофібри для кузова, скла та інтер'єру.
