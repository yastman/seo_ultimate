# Розпилювач для води

Розпилювач для води — обов'язковий інструмент для безконтактного догляду за машиною. Якщо хочете наносити активну піну рівномірно — обирайте піногенератор для мийки високого тиску. Для локальних робіт без обладнання підійде пінна насадка або помповий тригер.

## Як обрати розпилювач для води

| Тип | Принцип роботи | Для кого |
|-----|----------------|----------|
| Піногенератор для мийки (foam lance) | Підключається до Karcher/інші | Власники мінімийок |
| Помповий розпилювач для води | Ручне накачування | Без обладнання, мобільність |
| Пінна насадка (тригер) | Спрей без тиску | Локальне нанесення |

**Сценарії вибору:**
- **Якщо є мінімийка** → піногенератор для мийки з регулюванням густоти
- **Якщо немає мінімийки** → помповий розпилювач для води 2–5 л
- **Якщо для інтер'єру** → пінна насадка з тригером

### На що дивитися при виборі

| Параметр | Значення |
|----------|----------|
| Сумісність | Тип підключення до мінімийки |
| Об'єм бачка | 0.5–1л для foam lance, 2–5л для помпового |
| Регулювання піни | Можливість змінювати густоту |
| Матеріал | Латунь/нержавіюча — довговічніше |

## Типи піногенераторів для мийок

| Тип | Особливості | Коли брати |
|-----|-------------|------------|
| Стандартний foam lance | Базовий для більшості завдань | Побутове використання |
| З латунною форсункою | Довговічніший, стійкіший до хімії | Інтенсивна експлуатація |
| Багатофункціональний | Кілька режимів розпилення | Різні типи робіт |

## FAQ

### Чим foam lance відрізняється від звичайного спрея?

Піногенератор для мийки використовує тиск мінімийки для аерації — піна виходить густішою. Ручний варіант не дає такої густоти, але не потребує обладнання.

### Який об'єм бачка потрібен?

**Якщо одне авто** → 1л бачка foam lance достатньо. Для помпового на те саме авто — 2–3л для комфортної роботи.

### Яка пінна насадка краще?

Пінна насадка з регулюванням струменя дає більше контролю. Для інтер'єру — компактний тригер, для кузова — насадка більшого об'єму.

---

**Підсумок: як обрати розпилювач для води**
- Якщо є мінімийка: піногенератор для мийки з регулюванням густоти
- Якщо без обладнання: помповий варіант або пінна насадка
