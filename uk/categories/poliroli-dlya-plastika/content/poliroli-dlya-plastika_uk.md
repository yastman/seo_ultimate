# Поліролі для пластику

Поліроль для пластику авто — засіб для догляду за пластиком авто, торпедо, дверними картами та іншими пластиковими панелями салону. Правильний засіб для догляду за пластиком захищає від ультрафіолету, надає охайний вигляд і не створює жирного блиску.

## Як обрати поліроль для салону автомобіля

| Тип | Фініш | Для кого |
|-----|-------|----------|
| Матовий дресинг | Натуральний | Заводський вигляд, без блиску |
| Глянцевий | Мокрий ефект | Виражений лиск, шоу-кари |
| Сатиновий | Помірний | Баланс між матовим і глянцем |

**Сценарії вибору:**
- **Якщо авто з матовим пластиком** → матова поліроль для торпедо (глянцева виглядатиме штучно)
- **Якщо хочете «мокрий» вигляд** → глянцевий дресинг (поліроль для панелі авто)
- **Якщо не впевнені** → сатиновий фініш — універсальний варіант

### На що дивитися на етикетці

| Маркер | Значення |
|--------|----------|
| «Matte finish» | Не додає блиску |
| «UV protection» | Захист від вигоряння |
| «Anti-static» | Менше осідає пилу |
| «Non-greasy» | Не залишає жирної плівки |

## Особливості використання поліролі для пластику

Поліроль для салону наноситься на аплікатор, не безпосередньо на поверхню — це дозволяє контролювати кількість і уникати потрапляння на скло чи тканину. Після нанесення дайте засобу 2–3 хвилини для просочування, потім відполіруйте мікрофіброю.

**Якщо на поверхні залишається жирна плівка** → ви нанесли занадто багато; зніміть надлишок сухою мікрофіброю.

## Очищувач пластику авто vs поліроль

Очищувач пластику авто — для видалення забруднень, дресинг — для захисту та естетики. Правильна послідовність: спочатку очищувач, потім засіб для догляду.

**Відновлювач пластику** працює глибше — проникає в структуру та відновлює колір вицвілих панелей. Відновлювач кольору пластику особливо ефективний для чорних панелей, що посіріли від сонця.

### Поліроль для чорного пластику

Чорні панелі вимагають особливої уваги — будь-яка подряпина помітна. Поліроль для чорного пластику маскує мікроподряпини та повертає насичений колір.

## Поліролі для металевих елементів

Крім панелей, в салоні та на кузові є металеві деталі — молдинги, накладки, диски.

| Тип | Призначення |
|-----|-------------|
| Поліроль для хрому | Блискучі хромовані елементи |
| Поліроль для металу | Матові металеві поверхні |
| Поліроль для дисків | Литі та ковані диски |

## Що впливає на стійкість

| Фактор | Вплив |
|--------|-------|
| Чистота поверхні | Брудна панель = слабке зчеплення |
| Тип поверхні | Текстурована тримає краще |
| Вплив сонця | УФ-захист подовжує ефект |

## FAQ

### Чим дресинг відрізняється від силіконового спрею?

Це формула, розроблена для автомобільних панелей: містить UV-фільтри, антистатик і не притягує пил. Побутовий силіконовий спрей може створювати занадто жирну плівку і не має захисних властивостей.

### Як часто потрібно обробляти панелі?

**Якщо авто стоїть на сонці** → раз на 2–3 тижні для підтримки UV-захисту. Якщо в гаражі — раз на місяць-два для естетики.

### Чи можна використовувати на керму?

Не рекомендується — дресинг може зробити кермо слизьким. Для керма використовуйте спеціальні очищувачі без силіконових добавок.
