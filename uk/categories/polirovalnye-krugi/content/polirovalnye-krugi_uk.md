# Круги для полірування авто

Круги для полірування авто впливають на результат не менше, ніж паста — жорсткість і структура визначають зняття лаку, тепловідведення та фінішний блиск. Полірувальні круги бувають різних типів, і кожен підходить для своєї задачі. Якщо потрібен агресивний зріз на окисленому ЛФП — обирайте вовняну або жорстку поролонову насадку. Для фінішу без голограм підійде м'який поролон з відкритою коміркою.

## Як обрати круги для полірувальної машини

| Матеріал | Особливості | Для кого |
|----------|-------------|----------|
| **Поролон** | Універсальний, варіюється за жорсткістю. Відкрита комірка (open cell) менше гріється | Новачки та професіонали — базовий вибір |
| **Вовна** | Холодна робота, швидкий зріз. Ресурс 20+ обробок | Важка корекція, жорсткі японські ЛФП |
| **Мікрофібра** | Баланс: зріз як у вовни, фініш ближчий до поролону | Одноетапна корекція, середні дефекти |

**Сценарії:**
- **Глибокі подряпини, окислення** → вовняний круг для полірування або жорсткий поролон (cutting)
- **Середня корекція за один прохід** → мікрофібра або поролон середньої жорсткості
- **Фініш без голограм** → м'який поролон (finishing, чорний/білий)
- **Нанесення воску або силанту** → найм'якший поролон (extra soft)

### Жорсткість: що означає колір

Виробники використовують кольорове маркування, але воно не стандартизоване — помаранчевий у одного бренду може бути cutting, у іншого light cutting. Орієнтуйтесь на опис, а не лише на колір.

| Рівень | Типові кольори | Призначення |
|--------|----------------|-------------|
| Heavy Cut | Помаранчевий, жовтий | Перший прохід, глибокі дефекти |
| Medium Cut | Зелений, синій | Універсальна корекція |
| Finishing | Чорний, білий | Фініш, антиголограма |
| Extra Soft | Червоний, фіолетовий | Віск, силант, фінальний блиск |

### Діаметр диска для полірування

| Розмір | Коли обирати |
|--------|--------------|
| 75-90 мм | Кути, деталі, фари, інтер'єр |
| 125 мм | Малі та середні панелі, стандарт для DA |
| 150 мм | Великі плоскі панелі — дах, капот |

## Відкрита vs закрита комірка

Структура піни впливає на тепловиділення більше, ніж жорсткість. Відкрита комірка (open cell) пропускає повітря — насадка працює холодніше та безпечніше для ЛФП. Закрита комірка (closed cell) жорсткіше ріже, але перегрівається без частих перерв.

Для роботи на DA-машинці відкрита комірка краща. Закриту використовують на роторі при важкій корекції — потребує досвіду.

## Скільки кругів потрібно для полірування

Мінімальний набір кругів для полірування — три штуки: жорсткий (різка), середній (основна робота), м'який (фініш). Використовувати один диск для різних паст — помилка: залишки абразиву від компаунду завадять фінішній обробці.

Оптимально мати 5-6 кругів різної жорсткості, особливо при роботі з різними типами ЛФП.

## FAQ

### Вовняний круг для полірування залишає голограми?

Не обов'язково. Голограми з'являються при неправильній техніці або якщо не завершити роботу фінішним диском. Якісна вовна на правильних обертах дає хороший результат без додаткових проходів.

### Який круг на липучці обрати новачку?

Почніть із м'якого або середнього поролонового круга з відкритою коміркою. Такий круг для полірування безпечніший — менше ризику перегріти лак або залишити голограми. Робота з DA-машинкою та такою насадкою пробачає помилки.

### Як зрозуміти, що насадку пора міняти?

Якщо після чищення диск не відновлює ефективність — піна втратила структуру. Поролоновий круг витримує 5-10 обробок, мікрофібра 10-20, вовна 20+. Міняйте насадку, якщо липучка перестала тримати.

### Плоский чи хвилястий (waffle)?

Плоский дає більше контакту з поверхнею — ефективніший на великих панелях. Хвилястий краще відводить тепло завдяки повітряним кишеням. Для новачка різниця некритична — обирайте за вподобанням.

---

**Підсумок:** Полірувальні круги для базової корекції — це набір поролонових насадок трьох жорсткостей. Хутровий круг для полірування потрібен при роботі з жорсткими ЛФП або глибокими дефектами. Мікрофібра — компроміс для одноетапної обробки.
