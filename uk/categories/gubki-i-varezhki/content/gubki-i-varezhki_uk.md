# Губки та рукавички для миття

Губка для авто та мочалка для авто — базові інструменти ручного миття, які визначають безпечність процесу для лакофарбового покриття. Якщо ви миєте машину самостійно, правильний вибір між поролоном, мікрофіброю та шерстю збереже лак від подряпин. Рукавиця для миття авто зручніша за класичну губку автомобільну і краще утримує піну.

## Як обрати губку для автомийки

| Матеріал | Особливості | Для кого |
|----------|-------------|----------|
| Поролон | Великі пори, швидко набирає воду | Регулярне миття, новачки |
| Мікрофібра | М'яка, утримує бруд у волокнах | Делікатний догляд, темний лак |
| Шерсть (рукавиця з овчини) | Максимальна м'якість, преміум | Детейлери, цінний лак |
| Губка меламінова | Для стійких плям на пластику | Салон, гума, пластикові деталі |

**Сценарії вибору:**

- **Якщо миєте авто раз на тиждень** → поролоновий виріб з великими порами — дешевий та практичний
- **Якщо темний лак і важливо уникнути подряпин** → мійна рукавичка з мікрофібри
- **Якщо працюєте з преміум автомобілями** → рукавиця з овчини (wash mitt) — найбезпечніший варіант
- **Якщо потрібно нанести захист** → губка для нанесення воску або полімеру

### Губка для полірування авто чи рукавичка — що краще

Класичний поролоновий виріб добре набирає воду та піну, але вимагає частого полоскання. Бруд осідає на поверхні і може дряпати лак. Інструмент для полірування має дрібніші пори та м'якішу структуру.

Рукавичка зручніше сидить на руці, а її волокна захоплюють бруд всередину. Після кожної панелі достатньо прополоскати у відрі з чистою водою.

## На що звернути увагу при виборі мочалки для авто

| Характеристика | Що означає | Рекомендація |
|----------------|------------|--------------|
| Великі пори | Утримує більше піни | Для ефективного миття |
| Двостороння | Різні текстури | Універсальне застосування |
| Петля/кріплення | Фіксація на руці | Зручність використання |
| Chenille/синель | Довгий ворс | Делікатне очищення |

## Особливості використання

Будь-який мийний інструмент потребує попереднього замочування у мильному розчині. Суха поверхня може накопичувати статику і притягувати пил.

Використовуйте метод двох відер: одне з шампунем, інше з чистою водою для полоскання. Це запобігає перенесенню бруду назад на лак.

## FAQ

### Як часто міняти губку?

Поролонову — кожні 2-3 місяці при активному використанні. Мікрофіброву рукавичку — раз на рік при правильному догляді. Шерстяну wash mitt — може служити роками.

### Чи можна мити двигун тією ж губкою?

Ні, для моторного відсіку використовуйте окрему щітку або дешевий поролон. Жир та пил з двигуна забруднять інструмент для кузова.

### Яка різниця між поролоном та мікрофіброю?

Поролон утримує піну на поверхні, мікрофібра — захоплює бруд у волокна. Для темного лаку мікрофібра безпечніша, для швидкого миття світлого кузова — поролон практичніший.

### Як доглядати за рукавичкою?

Після миття ретельно прополощіть у чистій воді та висушіть на повітрі. Мікрофібру та шерсть можна прати в машинці без кондиціонера.

**Підсумок:**
- Якщо бюджетний варіант — поролонова мочалка для авто з великими порами
- Якщо темний лак — мікрофіброва рукавиця для миття авто
- Якщо преміум клас — рукавиця з овчини (wash mitt)
